Go Duel

Cloudflare Workers + Durable Objects 实时双人围棋

这是什么

一个可直接部署到 Cloudflare 的实时围棋对战项目：创建 6 位房间码 → 把链接发给朋友 → 两人打开网页即可落子。零数据库、零账号，每个房间由一个 Durable Object 实例托管状态。

Workers Durable Objects WebSocket Hibernation Workers Assets

目录结构

src/index.tsWorker 路由：/ws → DO，其余 → 静态资产
src/game-room.tsGameRoom DO：状态机、校验、持久化、广播
src/shared/go.ts规则引擎：气、提子、自杀、劫、数子法
src/shared/types.ts消息协议与房间状态类型
public/index.html单页前端（Canvas 棋盘，无构建）
public/app.jsWebSocket 客户端与渲染
tests/go.test.ts规则引擎测试用例
README.md部署步骤、协议说明、改路数方法

本地运行

npm install
npx wrangler dev        # 打开 http://localhost:8787
注意：必须通过 wrangler dev 启动后再访问，直接双击打开 public/index.html 是 file:// 协议，无法连接 /ws。

部署

npx wrangler login
npx wrangler deploy     # 输出 https://go-duel.<子域>.workers.dev

把 https://你的域名/?room=ABC123 发给朋友即可开战。

规则范围

  • 黑先交替落子；不能下在已有棋子处、不能自杀、简单劫禁止立即回提
  • 自动提掉对方无气棋块；支持 Pass，连续两次 Pass 终局
  • 终局按简化中国规则数子法计分（盘面棋子 + 单色围空），白方贴目默认 7.5
  • 默认 19 路，改 DEFAULT_BOARD_SIZE 一行即可切到 9 或 13 路
